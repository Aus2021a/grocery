# Load & Operations Management Portal

A lightweight, mobile-responsive web application for tracking operational load completion, managing team rosters, and analyzing labor variance metrics.

## Features
- **Load Entry & Tracking:** Log incoming load volumes and required labor hours.
- **Roster & Hours Management:** Track scheduled vs. actual hours worked.
- **Carton Rate & Efficiency Calculators:** Monitor carton rates and labor variance.
- **Mobile-Optimized Interface:** Designed for quick navigation on mobile devices and tablet dashboards.
